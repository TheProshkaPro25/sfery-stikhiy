# «Сферы Стихий»: прототип (Godot 4.x, GDScript)

Оригинальный мир. Ничего из Bakugan (имена, существа, дизайн) не использовать.
Один игрок (0) против ИИ (1), одна арена, графика только заглушки (примитивы).

## 1. Правила (первый баланс)

Атрибуты (цикл): Пламя > Буря > Свет > Камень > Тень > Прилив > Пламя.
Атрибут, бьющий атрибут соперника, получает +60 к силе. Против остальных трёх нет бонуса.

Существа (БС = базовая сила): 8 видов, каждый во всех 6 стихиях — 48 существ (см. «Виды и стихии» ниже).

Колода: у каждого игрока 3 существа, 3 карты арены, 3 карты способностей. Игрок: фиксированный пресет;
ИИ: случайно из общего пула. Экземпляры существ различаются по uid.

Карты арены (12):
- 6 «Полей»: Поле X даёт +100 существу атрибута X (effect `attr_bonus`).
- Низина: существо с меньшей БС получает +120.
- Пустота: преимущество атрибутов не учитывается.
- Перевес: преимущество атрибута удваивается (+120).
- Ловушка: атакующий получает −80.
- Бастион: защитник получает +80.
- Сумерки: Свет и Тень получают +70.

Карты способностей (8), каждая играется один раз за матч, не больше одной на игрока за бой:
- Рывок: +80 себе. Подсечка: −80 сопернику.
- Перелив: на этот бой твой атрибут становится тем, который бьёт атрибут соперника.
- Глушитель: отменяет карту арены. Щит: отменяет способность соперника.
- Наследие: +40 за каждое своё выбывшее существо.
- Родная стихия: +100, если твой атрибут совпадает с атрибутом «Поля».
- Ва-банк: +130, при поражении теряешь случайную способность из руки.

Поле: сетка 2×3, 6 слотов. Подготовка: игроки по очереди кладут по 3 карты арены рубашкой вверх (первым P0).
Свою карту владелец видит, чужую нет.

Ход:
1. Выбрать существо из руки. Отзыва с ворот нет (2026-10-27): если бросать некого, ход пропускается (`turn_skipped`); если некого обоим — бой в тупике (`standoff`, см. ниже).
   Отозванное существо не может приземлиться в слот, из которого его отозвали (`own_slot`, ход потерян): иначе при полном поле ходы шли по кругу до лимита.
2. Бросок: игрок задаёт направление и силу, ИИ задаёт цель и разброс.
3. Шар останавливается, 3D-слой сообщает слот (или −1).
4. Исход:
   - промах, вылет или пустой слот без карты: существо возвращается в резерв (reason `miss` / `empty_slot`);
   - слот со своим существом: возвращается в резерв, ход потерян (`own_slot`);
   - свободный слот с картой: существо раскрывается и стоит там, карта остаётся закрытой;
   - слот с существом соперника: бой.

Бой:
1. Карта открывается.
2. Окно способностей: сначала атакующий играет карту или пасует, затем защитник.
3. Расчёт силы. При ничьей побеждает защитник.
4. Проигравшее существо выбывает. Победитель возвращается в резерв и захватывает карту, слот становится пустым.

Порядок расчёта силы (`PowerCalc`, детерминированный):
1. БС. 2. Щит отменяет способность соперника. 3. Перелив меняет атрибуты. 4. Эффект карты арены, если не сыгран Глушитель.
5. Преимущество атрибута: Пустота обнуляет, Перевес удваивает; при Пустоте Перевес игнорируется.
6. Плоские модификаторы способностей. 7. Нижняя граница `max(0, …)`.

Победа: первым захватить 3 карты или оставить соперника без живых существ. Лимит 40 ходов: по числу захваченных карт,
затем по сумме БС живых существ, затем ничья.

## 3. Контракт модулей

`enum Phase {SETUP, AWAIT_THROW, AWAIT_LANDING, ABILITY_WINDOW, RESOLVING, GAME_OVER}`. Игроки: 0 = человек, 1 = ИИ.

### (А) MatchController
- `_init(deck0: DeckDef, deck1: DeckDef, rng_seed: int)`, `start() -> void`
- Действия: `place_arena_card(player, card_id, slot) -> Error`; `select_creature(player, uid) -> Error` (при пустом резерве делает отзыв, фаза -> AWAIT_LANDING);
  `report_landing(uid, slot) -> void` (-1 = промах/вылет; единственный вход из физики); `play_ability(player, card_id) -> Error`; `pass_ability(player) -> Error`
- Запросы: `get_view(player) -> MatchState` (чужие закрытые карты замаскированы, card_id пустой); `get_phase()`; `get_active_player()`;
  `legal_creatures(player) -> Array[int]`; `legal_setup_slots() -> Array[int]`; `legal_abilities(player) -> Array[StringName]`
- Сигналы: `phase_changed(phase, active_player)`, `setup_requested(player)`, `arena_card_placed(player, slot)` (без card_id), `throw_requested(player)`,
  `creature_selected(player, uid, recalled)`, `creature_returned(uid, reason)`, `creature_stood(uid, slot)`, `battle_started(slot, attacker_uid, defender_uid)`,
  `card_revealed(slot, card_id)`, `ability_window(player, options)`, `ability_played(player, card_id)`, `ability_cancelled(player, card_id)`,
  `battle_resolved(result)`, `creature_eliminated(uid)`, `card_captured(player, slot, card_id)`, `turn_started(player, turn)`, `game_over(winner, reason)` (winner −1 = ничья)
- Контроллер сначала полностью меняет состояние, потом эмитит сигналы. Без `await`, синхронный и детерминированный при фиксированном seed.

### (А) AIPlayer
- `_init(player, rng_seed, aim_error = 0.6)`
- `choose_setup(view) -> Dictionary {card_id, slot}`; `choose_throw(view) -> Dictionary {uid, target_slot}`;
  `choose_ability(view, preview: BattleResult) -> StringName` (`&""` = пас; минимальная карта, которой хватает для победы); `get_aim_error() -> float`
- Приоритеты броска: бой с ожидаемым перевесом > 40; своя закрытая карта, подходящая по атрибуту; свободный слот. Чужую закрытую карту считать нейтральной.

### (Б) 3D-слой (вызывает только методы выше, состояние не меняет)
- Arena: `slot_position(i) -> Vector3`; `slot_at(world_pos) -> int` (ближайший центр по XZ в пределах 1.0, иначе −1; y < −1 даёт −1; шаг сетки 2.4); `set_highlight(slots: Array[int])`
- CreatureBall: `setup(def, uid)`, `launch(impulse)`, `open_up()`, `close_up()`, `freeze_at(pos)`, `signal settled(ball, world_pos)`
- ArenaCardNode: `show_facedown(owner, visible_to_owner_def)`, `reveal(def)`, `play_capture(to_player) -> Signal`
- ThrowController: `signal throw_committed(impulse)`, `enable(ball)`, `disable()`, `static impulse_for_target(from, to, error, rng) -> Vector3`
- AbilityPanel: `signal ability_chosen(card_id)`, `signal passed()`. SetupPanel: `signal placed(card_id, slot)`. BattleOverlay: `show_result(r) -> Signal`.
- EventPlayer: `push(callable_anim)`, `signal drained()`.
- main.gd: все сигналы контроллера идут в EventPlayer. Ввод/ход ИИ включается только после `drained` и только в фазах AWAIT_THROW / ABILITY_WINDOW / SETUP.
  `settled` превращается в `report_landing(uid, arena.slot_at(pos))`.

## 4. Риски и решения
1. Повторный вход в сигналах: состояние меняется до эмита; в main ответы через EventPlayer или `call_deferred`.
2. Шар не засыпает: `settled`, если |v| < 0.05 держится 0.3 с; таймаут 5 с фиксирует позицию. `continuous_cd = true`, `angular_damp = 1.5`.
3. Шар между слотами: радиус 1.0 при шаге 2.4; всё вне зон = промах; тест `slot_at` на граничных точках.
4. Стоящие существа: `freeze = true` (FREEZE_MODE_STATIC) после `creature_stood`.
5. Утечка скрытой информации к ИИ: ИИ получает только `get_view(1)`; тест на пустой card_id.
6. Порядок эффектов: один `PowerCalc`, поле breakdown, тест на каждую пару.
7. Тупик «все существа стоят»: пропуск хода, у обоих — бой сильнейших стоящих (`standoff`); лимит 40 ходов.
8. Мутация общих Resource: в рантайме только uid и CreatureState.
9. GDScript 4: `Array[int]` требует `assign()`; `int/int` целочисленное; core не ссылается на scenes; без `await` в core.
10. Промахи ИИ: `aim_error` подобрать так, чтобы доля попаданий в 300 бросках ≈ 65%.

Минимальные headless-тесты: таблица преимуществ 6×6; ничья за защитником; каждая карта отдельно; Щит/Глушитель/Пустота/Перевес;
отзыв при пустом резерве; победа за 3 карты; победа при отсутствии существ; лимит ходов и тай-брейк; одинаковый seed даёт одинаковый лог.

## Новые способности (2026-10-26)

Механики взяты по мотивам карт способностей Бакуганов, а названия, тексты и дизайн свои. Всего в пуле 20 карт.
- **Стихийные** (`params.lock`): сыграть может только существо этой стихии (по исходному атрибуту). Огненный смерч: +70/−70.
  Встречный ветер: +40 и чужое преимущество стихии. Ослепление: сила соперника не выше его БС. Гранитная стена: +90, в защите +160.
  Поглощение: половина бонусов соперника сверх БС. Водоворот: +30 и обмен стихиями.
- **Слияние** (`params.fusion`): играется только сразу после своей основной способности в том же окне (контроллер открывает
  окно слияния для той же стороны). Резонанс удваивает числа основной карты, Цепная искра: +50 и защита от Щита,
  Отголосок: +30 за каждую сыгранную за матч способность. Без действующей основной карты слияние не работает.
- **Особые**: Перехват поля (бонус арены соперника переходит к тебе), Обмен сутью (обмен БС), Спасение (+20; проигравший
  не выбывает, а возвращается в резерв, карту всё равно захватывают; событие `creature_returned(uid, &"rescued")`).
- Колода получает стихийные карты только под стихии своей команды и не больше одного слияния (`CardDB._pick_abilities`).
- API: `PowerCalc.compute(..., atk_fusion, def_fusion)`, `AIPlayer.choose_ability(view, preview, legal)`, где `legal = ctrl.legal_abilities(p)`.

## Правила по Бакугану (2026-10-27, по официальной инструкции Spin Master)

Эти правила заменяют раздел 1 в части хода и боя. Расчёт силы (`PowerCalc`) прежний, но к нему добавлена G ворот.
- **Начало:** поле пустое. Каждый ход начинается с выкладки карты ворот (фаза SETUP): класть по желанию (`skip_gate`),
  но обязательно, если на поле нет ворот. Место выбирается из свободных слотов рядом с уже лежащими картами,
  по возможности в ряду ближе к сопернику (P0 — слоты 0..2, P1 — 3..5): `legal_setup_slots()`.
- **Бросок:** бросать можно только существо из руки (не на поле и не в зоне использованных).
  - Промах (мимо ворот) уводит существо в зону использованных, ход переходит сопернику.
  - Пустые ворота: существо встаёт на них, ход переходит сопернику.
  - Ворота со своим существом: бросок переставляется на другие ворота без своего существа, сначала туда, где стоит соперник
    (`creature_relocated`). Если таких ворот нет, карта засчитывается игроку, оба его существа уходят в использованные.
- **Бой:** сначала окна способностей (атакующий, затем защитник; ворота ещё закрыты, предпросмотр по виду игрока),
  потом `card_revealed` и расчёт. Победитель забирает карту и ходит следующим. Оба бойца уходят в использованные,
  проигравший не выбывает (`creature_returned(uid, &"lost"/&"won")`). При ничьей побеждает защитник, то есть тот, кто встал первым.
- **Зона использованных:** когда бросать некого, все использованные возвращаются в руку (`creatures_refilled`).
  Если все три существа стоят на воротах, ход переходит сопернику. Если бросать не может ни один игрок, партия заканчивается (`stalemate`).
- **G ворот** (`params.g`, 6 значений по стихиям): «Поле X» даёт +amount стихии X и +30 остальным, особые карты дают G = 0.
- **Карты:** «Наследие» теперь +40 за каждое своё существо в зоне использованных. «Спасение»: при поражении карта
  остаётся на поле и не достаётся сопернику.
- **Победа:** 3 карты ворот. Лимит 60 ходов: по числу карт, затем по силе команды, иначе ничья.
- Симуляция 200 матчей ИИ против ИИ: 97% партий заканчиваются захватами, средняя длина 13.6 хода.

## Колода бойца и победа нокаутом (2026-10-27)
- **Победа:** выбить всех трёх существ соперника (`knockout`). Проигравший в бою выбывает, победитель уходит в зону
  использованных, карта ворот достаётся победителю. «Спасение»: проигравший не выбывает. «Наследие»: +40 за каждое выбывшее своё существо.
- Если в руке пусто и все живые существа стоят на воротах, можно снять своё существо с ворот и бросить снова.
- Если ворота кончились у обоих, выигранные карты возвращаются в руки (`gates_recycled`). Лимит 60 ходов: по числу живых существ.
- **Колода по правилам Бакугана** (`CardDB.deck_error`): боец одной стихии, 3 разных существа этой стихии (сила ≤ 1100),
  ворота: по одной золотой (поля), серебряной (Низина/Ловушка/Бастион/Сумерки) и бронзовой (Пустота/Перевес),
  способности: по одной красной (стихийные, Перелив, Родная стихия; стихийная только своей стихии),
  синей (Рывок, Подсечка, Наследие, Ва-банк, Отголосок) и зелёной (Щит, Глушитель, Перехват, Обмен сутью, Спасение, Резонанс, Цепная искра).
  ИИ собирает колоду по тем же правилам (`CardDB.random_deck`).
- Поле стало просторнее: шаг карт 3.7×4.7·WORLD, пол 13.4×13.6·WORLD. Бросок откалиброван: `SPEED_PER_DIST = 1.34`.
- Симуляция 200 матчей ИИ против ИИ: 99% партий заканчиваются нокаутом, средняя длина ~20 ходов.


## Виды и стихии (2026-10-27)

Как в Бакугане, но со своими видами и именами: каждый вид существует во всех 6 стихиях. Существо = вид × стихия,
id `creature_<вид>_<стихия>`, имя «<Вид> <стихия в род. падеже>» («Драгнар Пламени»). Таблица `GameData.SPECIES`,
развёртка в `CardDB.species_creatures()`.

| Вид | БС вида | Силуэт (архетип) |
|---|---|---|
| Драгнар | 360 | дракон |
| Клыкарь | 330 | волк |
| Грифалон | 320 | грифон |
| Колоссар | 380 | циклоп-голем |
| Рогожук | 340 | жук-рогач |
| Левиан | 350 | морской змей |
| Ратник | 350 | рыцарь |

## Без отзыва: пропуск хода и бой в тупике (2026-10-27)
- Стоящие на воротах существа больше не снимаются. Если в руке пусто (после возврата из зоны использованных),
  игрок пропускает ход (`turn_skipped`).
- Если бросать некого обоим, существо с наибольшей БС у игрока, чей ход, переходит на ворота к сильнейшему
  стоящему существу соперника (`standoff`, затем `creature_relocated`) — дальше обычный бой.
- Симуляция 200 матчей: 100% нокаутом, средняя длина 17 ходов. Без боя в тупике было 71% матчей вничью-тупиком.

## Бой как в аниме: правила первого сезона и механики глубины (2026-10-28)

Ориентир — подача первого сезона аниме о призыве существ (поздние серии с нарушениями правил не учитываются).
Мир, названия и карты свои. Этот раздел заменяет «способности только до открытия ворот» и G ворот из раздела
«Правила по Бакугану»; остальное (выкладка ворот, бросок, нокаут, тупик) прежнее.

**Почему эти механики.** Анализ симуляции: бой решался одной картой с каждой стороны, а защитник всегда отвечал последним,
зная карту атакующего; ворота почти ничего не значили (+30 любой стихии), исход матча после первого нокаута был предсказуем.
Выбраны механики, которые дают напряжение внутри боя (обмен, ловушки), между боями (натиск, финал) и тактику броска
(ворота + бросок, способности вне боя). «Двойная стойка» отклонена: требует переделки расчёта на два существа и визуала
слота, а нынешняя перестановка на свои ворота уже закрывает этот случай.

1. **Способности в три момента** (приоритет пользователя).
   - *До броска*: существо выбрано (`AWAIT_LANDING`), `play_ability` прикрепляет карту к нему (`ability_attached`).
   - *После приземления* на пустые ворота: окно `AFTER_LANDING` (`attach_window`), карту можно прикрепить к вставшему
     существу или пасовать (пас = конец хода). Включается флагом `MatchController.landing_window` (пока интерфейс
     не готов — выключен; тесты и `tools/sim.gd` включают).
   - Прикреплённые карты видны обоим (`CreatureState.attached`), срабатывают в **следующем бою** существа первыми
     (по времени розыгрыша), снимаются после этого боя; промах их не снимает. Они **входят в лимит 3 карт** на бой.
   - *В бою*: ворота открываются сразу (`card_revealed`), затем **обмен**: поочерёдно, начиная с игрока, чей ход
     (атакующий); пас окончателен, после паса второй может доиграть; бой решается, когда оба вышли из обмена.
     Не больше `MAX_BATTLE_ABILITIES` = 3 карт на игрока за бой (с прикреплёнными). Каждая карта — раз за матч.
   - Слияние играется поверх своей последней основной карты, если на ней ещё нет слияния (не обязательно сразу).
   - **Щит в цепочке** (`PowerCalc.compute_seq`, разрешение с конца, как стопка): отменяет последнюю действующую основную
     карту соперника, сыгранную до него (с её слиянием); если такой нет — первую следующую основную карту соперника, кроме Щита.
     Щит на Щит возвращает отменённую карту. «Цепная искра» делает карты своей стороны неотменяемыми.
     Несколько основных карт одной стороны складываются; два «Обмена сутью»/«Водоворота» гасят друг друга (чётность).
2. **Ворота + бросок** (приоритет): `throw_with_gate(player, card_id, slot, uid)` в фазе выкладки кладёт карту и сразу
   бросает на неё существо (`arena_card_placed`, `gate_thrown`, `creature_selected`); цель броска — этот слот
   (`get_throw_gate_slot()`), приземление обычное, промах возможен. Обычная выкладка тоже осталась. Ворот на поле может быть много.
3. **Бонус ворот только своей стихии** (приоритет): «Поле X» +150 только стихии X (было +100 своей / +30 остальным).
   Серебряные: Низина +150, Бастион +100, Ловушка −100, Сумерки +70. Редкие золотые «Престол стихии» +500 защитнику
   стихии владельца ворот (команда одной стихии; атакующему 0). Диапазон 50–500, баланс проверен симуляцией (ниже), БС не менялись.
4. **Ловушки ворот** (3 бронзовые карты, `params.hidden_trap`): открываются в начале боя, `gate_trap_triggered(slot, card_id, effect)`.
   «Печать тишины» (seal) — в этом бою способности не играются, прикреплённые сгорают (`ability_cancelled`);
   «Зеркало» (mirror) — итоговые силы меняются местами (шаг 8); «Обратный ток» (backflow) — преимущество стихии у того,
   чью стихию бьют. Глушитель отменяет «Зеркало» и «Обратный ток» (не «Печать»). Блеф: соперник не знает, какая из
   закрытых карт — ловушка.
5. **«Натиск»**: победа в бою даёт +1 к серии (до 2), поражение сбрасывает (`momentum_changed(player, value)`),
   в бою +40 за каждую победу подряд (`PowerCalc.MOMENTUM_STEP/MAX`). Ускоряет развязку: без него матч 16.9 хода, с ним 15.
6. **Финальный раунд**: когда у кого-то впервые осталось одно существо — `final_round_started(player)` (−1 у обоих),
   `MatchState.final_round`, преимущество стихии ×2 до конца матча.

Порядок расчёта (`PowerCalc.compute_seq(state, atk, def, slot, battle_plays)`; старый `compute(...)` — обёртка):
0 отмены (Печать, Щиты) → 1 БС/Обмен сутью → 3 Перелив/Водоворот → 4 ворота (Глушитель, Перехват) → 5 преимущество
(Пустота, Перевес, Обратный ток, финал ×2, Встречный ветер) → 6 плоские карты и слияния → 6а Натиск → 6б Поглощение →
6в Ослепление → 7 max(0) → 8 Зеркало. Ничья — защитнику. `BattleResult`: `plays`, `battle_plays`, `cancelled_plays`,
`trap_id`, `sealed`, `mirrored`, `final_round`, `momentum`, `passed`.

**ИИ: три уровня** (`AIPlayer.new(player, seed, aim_error = -1, difficulty)`, `Difficulty.EASY/NORMAL/HARD`,
имена «Новичок/Боец/Мастер», разброс броска 0.62/0.42/0.30). Новичок: шумная оценка целей, пасует при перевесе и часто
просто так, карты наугад. Боец: самая дешёвая выигрышная карта, запас перевеса 80, если соперник ещё может ответить;
«ворота + бросок» под подходящее существо; приманка — слабейшее существо на своё «Зеркало»; после приземления прикрепляет
самую дешёвую карту, снимающую угрозу атаки (`choose_attach`). Мастер: блеф (ловушку кладёт первой), риск ловушки на
чужих закрытых воротах (по раскрытым картам соперника), ворота под существом соперника считает его «Полем», запас перевеса
растёт с числом карт, которыми соперник ещё может ответить, разыгрывает пару карт, если одной мало, оценивает угрозу
воротам перед тем, как встать. Детерминизм по seed сохранён.

**Симуляция** `godot --headless -s res://tools/sim.gd -- n=2400 seed=1 check=1` (ИИ «Боец» против «Бойца», случайные колоды
по правилам, модель броска как в тестах): старт P0 51.3 %, длина 15.0 хода (медиана 15, 10–90 % — 9–21), 100 % нокаутом;
стихии 44.7–56.3 % (Буря 44.7, Камень 46.3, Пламя 47.1, Прилив 50.6, Тень 54.5, Свет 56.3); в среднем за матч 4 боя,
2.4 карты в бою, 0.74 прикреплённых, 0.67 «ворот + броска». Уровни: Мастер — Боец 55.6 %, Боец — Новичок 60.9 %,
Мастер — Новичок 64.1 %.

### Расчёт и исходы
Порядок `PowerCalc.compute_seq`: 0 отмены («Глухие врата» гасят сторону; «Волчья хватка» — стопкой, кроме `sure`
и мгновенных; «Глубинная тишь» гасит следующие карты соперника; слияние без основы не действует; «Отпечаток в камне»

Контроллер (`_resolve`): «Отлив» — существо соперника встаёт на первые свободные ворота, второй боец — на ворота боя,
никто не выбывает, ход сопернику того, чей был ход. Выбывают оба — ворота сгорают (`gate_discarded`), натиск обоих
сбрасывается, ход сопернику; оба последних — ничья. «Удержание» — победитель стоит на воротах, карта лежит дальше.
Потом: «Возрождение» (первое выбывшее своё существо — в зону использованных), «Второе дыхание» и карты `returns`
(в руку), метки на живых. Мгновенные: «Попутный шквал» после приземления (`AFTER_LANDING`) переносит существо к самому
слабому стоящему сопернику и начинает бой (карта прикрепляется к бойцу: +120 в этом бою; без цели — обычное прикрепление);
«Вихревая подмена» — боец уходит в руку, сильнейшее своё существо не на воротах встаёт на его место (`fighter_swapped`);
«Сдвиг плит» — ворота боя меняются со своими свободными воротами, выгоднейшими по расчёту (`gates_swapped`, затем
`card_revealed`). «Зов павших» срабатывает при открытии ворот.

Новые сигналы `MatchController` (эмит после изменения состояния): `creature_revived(uid)`,
`creature_marked(uid, card_id, mark)`, `fighter_swapped(old_uid, new_uid, slot)`, `gates_swapped(slot_a, slot_b)`,
`gate_discarded(slot, card_id)`, `abilities_recalled(player, card_ids)`; перемещения — прежний
`creature_relocated(uid, from, to)` (`from == to` — существо остаётся/центрируется на воротах). `main.gd` показывает
их баннером/вспышкой/тряской и строкой ленты, плашка бойца снова зажигает шарик возрождённого (`Hud.revive_creature`).

**ИИ** (все уровни): предпросмотр каждой карты через `PowerCalc.compute_with` (мгновенные считаются на копии
состояния), оценка исходов `_margin`: «Отлив» = 0.25 (лучше поражения), «Общая бездна» — спасение для проигрывающего и
повод отменить её для выигрывающего, «Трон сумрака»/«Предел» решают бой без сил. «Попутный шквал» в `choose_attach`
(Новичок — при любом перевесе через раз, Боец > 40, Мастер > 60). Ворота подбираются по стихии, виду и Трону сумрака;
приманка на «Зеркало»/«Обоюдный удар»/«Предел» — слабейшее существо, «Глухие врата» — когда у соперника больше карт;
риск ловушки у Мастера — 4/10 командных ворот.

### Обоснование баланса
- Стихийные бонусы ворот разные (Камень 150, Буря 150, Прилив 130, Пламя 120, Свет 90, Тень 80): у Тени слабое Поле,
  но «Трон сумрака», «Общая бездна» и самые резкие стихийные; у Света — «Возрождение».
- Сильнейшие разовые карты — перекачки (Пожирающий жар ±100, Кольца глубин) и потолки силы (Пучина, Великий сброс):
  они видовые или стихийные, поэтому у колоды максимум одна такая карта каждого класса.
- Мгновенные карты Бури и Камня в одиночку почти не влияли на исход (Буря 36–39 %), поэтому им добавлена сила:
  шквал +120, подмена +150, сдвиг +50; Поле Бури 150.
- Камбэки: по симуляции решает не одна большая карта, а повторяемая: лесенка «меньше существ / последнее существо»
  с `returns` подняла камбэки с 22 % до 25–27 %; «Возрождение», «Зов павших», «Отлив» добавляют ещё.
