# Скелеты v2

`upgrade_rigs.py` обновляет GLB без переэкспорта геометрии и текстур. Добавляет опоры плеч у гуманоидов,
кисти/стопы и опоры краёв крыльев там, где есть соответствующие родительские кости. Старые глобальные
позы покоя сохранены. Это расширение и очистка существующей привязки, а не ручная перестановка каждого
сустава или полный анатомический ремоделинг.

Веса ограничены локальной иерархией; совпадающие точки на UV-швах получают одинаковые веса.
После выбора четырёх влияний веса нормализуются. Дополнительные суставы получают умеренные ключи
сгибания. Положение дистальных опор определяется распределением действительно привязанных вершин.

Запуск: `python3 tools/models/upgrade_rigs.py --species kolossar`. Без `--species` — 48 моделей.
По умолчанию оригиналы сохраняются в `/tmp/sfery-rig-v1`. Для долговременной работы задавайте отдельную
папку `--backup`. Повторный запуск использует оригиналы v1. Если оригиналов нет, готовые v2 пропускаются.
Версию v1 можно восстановить из тега `v0.2.3`; изменённый исходник требует новой папки backup.

Проверка: `python3 tests/rig_integrity.py`, при наличии оригиналов добавить `--reference /tmp/sfery-rig-v1`.
Проверки движения: `godot --headless -s res://tests/animation_tests.gd`.
Запись кадров: `godot -s res://tools/animation_review.gd -- creature_kolossar_light /tmp/anim`.

Кубическое сглаживание и ручной таймлайн клипов находятся в `scenes/creature_anim.gd`.
STEP в исходниках в основном относится к постоянным translation/scale; основными причинами рывков
были независимые таймеры, отменяемые твины и жёсткие переходы. Очистка STEP сама по себе их не исправляет.
