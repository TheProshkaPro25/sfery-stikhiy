# План: бой как в аниме (2026-10-28)

Цель: матч должен смотреться как сцена боя из аниме-сериала о призыве существ (сезон 1 «Бакугана» — ориентир по
**подаче**, не по содержанию): огромное поле, работа камеры, напряжённый интерфейс, глубже геймплей.
Мир свой: названия, существа, карты и дизайн чужого IP не используем — только механику «шар → ворота → бой по силе».

## Общие правила для всех потоков
- Godot 4.7, GDScript. `core/` — чистая логика без Node, без `await`; `scenes/` — визуал и ввод. Не ломать контракт DESIGN.md §3.
- Тесты: `godot --headless -s res://tests/run_tests.gd` (сейчас 585/0). Автоигра: `godot --headless -s res://tools/autoplay.gd`
  (2 матча, проверка на зависание). Кадры: `godot -s res://tools/shot.gd -- <папка>` (окно, 80 кадров) → `magick montage`.
  Запускать Godot **по одному процессу за раз** на снимки (окно); headless-тесты можно параллельно.
- Производительность: ноутбук, RTX 4070 8 ГБ. Цель 60 fps в 1080p; никаких тяжёлых пост-эффектов поверх уже включённых SSAO/теней.
- Комментарии и строки в коде по-русски, в стиле соседнего кода. Нет новых зависимостей и скачиваний.
- Каждый поток пишет в конец этого файла раздел «Отчёт <поток>»: что сделано, что не вышло, что нужно другим.
- Git: базовый коммит сделан. Каждый поток коммитит свою работу `git commit` (только свои файлы, `git add <пути>`).

     автора способности с рывком → удар: быстрый наезд + тряска (есть `shake`) → победитель: медленный облёт;

3. **Шар и бросок.** Траектория дальняя и зрелищная: шар летит дугой, катится с искрами и следом по полю; прицел —

### ТЗ для потока В (интерфейс)
Сигналы контроллера (новые; все эмитятся после изменения состояния, как прежние):
- `ability_attached(player, uid, card_id)` — карта сыграна вне боя и прикреплена к существу uid (значок карты над шаром/
  существом, звук способности). Прикреплённые карты: `view.creature(uid).attached` → `[[метка, card_id], ...]`, видны обоим.
- `attach_window(player, uid, options)` — окно «после приземления» (фаза `Phase.AFTER_LANDING` = 6, приходит и
  `phase_changed`). Человек: панель способностей с options + «Пас»; ответ `play_ability(p, id)` (окно может открыться снова,
  пока есть карты и лимит) или `pass_ability(p)` (конец хода). ИИ: `ai.choose_attach(ctrl.get_view(1), ctrl.get_landed_uid(),
  ctrl.legal_abilities(1))` → `&""` = пас. **В `_pump` добавить фазу AFTER_LANDING**, затем включить `ctrl.landing_window = true`
  сразу после создания контроллера в `_build_logic`.
- `gate_thrown(player, slot, uid)` — «ворота + бросок»: анимация карты, летящей вместе с шаром в slot (следом
  `arena_card_placed` уже пришёл, затем `creature_selected`, фаза AWAIT_LANDING). Цель броска ИИ — `ctrl.get_throw_gate_slot()`.
- `gate_trap_triggered(slot, card_id, effect)` — сразу после `card_revealed` в начале боя; effect `seal`/`mirror`/`backflow`
  (плашка «ЛОВУШКА!», кат на ворота). Итог: `BattleResult.trap_id` (пусто, если Глушитель отменил), `sealed`, `mirrored`.
- `momentum_changed(player, value)` — серия побед 0..2 (`PowerCalc.MOMENTUM_STEP` = 40 за ступень): огоньки у портрета.
- `final_round_started(player)` — один раз за матч (−1 — у обоих по одному): объявление «ФИНАЛЬНЫЙ БОЙ», музыка battle_final;
  `ctrl.is_final_round()`, `view.final_round`, `BattleResult.final_round` (преимущество стихии ×2).
